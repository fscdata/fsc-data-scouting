Export scouting data

This export produces a CSV using the current 2026 (REBUILT) schema: match_number, team_number, notes, start_position, auto fields, teleop fields (fuel / hub counts), endgame, and bonus RPs: Energized, Supercharged, Traversal.

Tip: Set minimum match to 0 to export all matches, or set a match number to export from that match onward.
