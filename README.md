# fsc-data-scouting
FIRST SC Scouting Alliance data collection and sharing website

# setup and installation

The data collection website can be executed wherever there is an accessible database. This can be as simple as a SQLite database created in the same directory for local install and testing, or a path to a more enterprise-scale database for more permanent server-based installations. This flexibility is accomplished with the [SQL Alchemy library](https://www.sqlalchemy.org/).
